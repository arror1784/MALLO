# 참고 문서 (부록)

이 디렉토리는 코드가 아니라 배경 문서를 가리키는 안내다. 실제 문서는
레포 루트에 있다.

- `../../MALLO_사업계획서.md` — 서비스 기획 배경. 이 레포(1단계 화면
  프로토타입)의 최신 구현 상태를 반영하지 않는다. 사업 방향이 바뀌면
  이 문서와 실제 화면 구현이 어긋날 수 있다.
- `../../MALLO-화면작업-브리핑.md` — 1단계 착수 시점(2026-09)에 작성된
  작업 방식 브리핑. 착수 시점 참고 자료이며, 실제 구현·규칙은
  루트 `CLAUDE.md`가 최신 상태를 반영한다. 두 문서가 다르면 `CLAUDE.md`를
  따른다.
